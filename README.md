# Portal de Proveedores V4 — UNITEC U.S.A.

Sistema de órdenes de compra a proveedores internacionales con generación de PDF y Excel.

## 🚀 Deploy en Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/TU-USUARIO/unitec-proveedores-v4)

## 🛠️ Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- jsPDF + jsPDF-autotable
- SheetJS (xlsx)

## 📦 Instalación

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000)

## 🌐 Production

```bash
npm run build
npm start
```

## 📝 Features

- ✅ Generación de órdenes de compra
- ✅ Export a PDF profesional
- ✅ Export a Excel
- ✅ Cálculos automáticos (peso, área)
- ✅ UI dark mode moderna
- ✅ Responsive design
- ✅ Login system

## 🔗 Deploy

Auto-deploy habilitado en Vercel. Cada push a `main` deploya automáticamente.
